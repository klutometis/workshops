      Infoboxes[edit source]

      In order to make keeping a unified style easier, I ported your work over to a new template: Template:Infobox.

      {{{header}}}
      {{{content}}}

      This can then be used in other templates:

      {{{name2}}} ideas
      [[File:{{{idea1icon}}}.png|28px]] {{{idea1}}}
      {{{idea1effect}}}

      [[File:{{{idea2icon}}}.png|28px]] {{{idea2}}}

      {{{idea2effect}}}

      [[File:{{{idea3icon}}}.png|28px]] {{{idea3}}}

      {{{idea3effect}}}

      [[File:{{{idea4icon}}}.png|28px]] {{{idea4}}}

      {{{idea4effect}}}

      [[File:{{{idea5icon}}}.png|28px]] {{{idea5}}}

      {{{idea5effect}}}

      [[File:{{{idea6icon}}}.png|28px]] {{{idea6}}}

      {{{idea6effect}}}

      [[File:{{{idea7icon}}}.png|28px]] {{{idea7}}}

      {{{idea7effect}}}

      Ambition:

      {{{bonus}}}

      This means that several templates can use the same unified style. At need we can extend the capabilities of the infobox template to make room for more complex templates. This should reduce replication of work by a good deal. ~ Meneth (talk) 13:06, 3 September 2013 (CEST)
