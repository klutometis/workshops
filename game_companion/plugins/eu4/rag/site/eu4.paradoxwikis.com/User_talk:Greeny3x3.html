      Thank you[edit source]

      Hi, I want to thank you for all the work which you did on this wiki. I was occupied with the vic3 wiki recently and didn't have much time for eu4. But you picked it up pretty well and did great work to update much of the wiki with the new information. I noticed that you capitalize a lot of words, but in english words should be lowercase unless they are proper nouns or at the start of a sentence. The names of things like government reforms, events, missions and so on count as proper nouns and you can use the same capitalization as the game. But game concepts like the word "government reform" itself should be lowercase. For example the sentence “The Refoms "Livonian Elective Monarchy" and "Supremacy of the Diet" disable the Estate Influence Gain from calling the Diet.” from one of your recent changes to the estates page could be better written as “The reforms Livonian Elective Monarchy and Supremacy of the Diet disable the estate influence gain from calling the diet.” Please have a look at the style guide. It has more information on how to write good wiki articles. --Grotaclas (talk) 05:44, 17 November 2022 (UTC)

      Hi, glad to hear from a fellow editor, i had feared the Eu4 Wiki had been abandoned as of late. I know about the capitalisation issues my articles have, i think its because of a mix of my native language and the game using a weird mix of lower and upper case words. Ill try to get better with that! I hope besides this issue my edits have met the quality standarts, i think i now got the hang of how to use Wikia.— Preceding unsigned comment added by Greeny3x3 (talk) 15:37, 17 November 2022‎ (UTC)
      Yeah the game often doesn't follow the capitalization rules of the English language. But we can try to do better on the wiki. To give you another example how you could improve the capitalization, I improved some of the changes from your last edit to the base estates in this edit. I have a few more suggestions how you can improve your contributions to the wiki:
      • First of all, don't let any of this discourage you from editing the wiki. Having the correct information in the wiki is more important than style.
      • if you reply to a comment on your talk page, it is better to do it on your talk page so that the context is clear. That's why I moved your comment from my talk page to your talk page.
      • please sign comments on talk pages by using ~~~~
      • please use "." as decimal separator and not ",". You are not the only one who made this mistake, so I wrote a quick script yesterday to fix it on the whole wiki, but I would like to avoid having to run this script over and over again.
      • please link government reforms, events, missions, or anything else which has a wiki article, when you refer to them(except basic concepts and things which you already linked before). This way readers can quickly look up more details. To make this easier for government reforms, I created redirects for all of them yesterday with a script. Linking is not needed when you use the {{icon}} template, because the icons already have a link. But this only works if you use the correct icon for something, so using {{icon|legendary pirate}} for pirate republics is not the best option, because it links to the personalities page. I could add as an icon for pirate republics, but I'm not sure if this is the best choice. Estate privileges and agendas can't currently be linked easily, because the tables don't have an id or anchor, but I can try if I can fix that semi-automatically.
      • Using italics together with quotes looks better than just quotes. If you use the text based editor, you can click on “Special characters” above the edit box and then select “Symbols” you can find the quotation marks which I used in this line. If you click on them while you have text selected, they will automatically be placed around the text.
      • the same “Symbols” also has the minus sign “−” (between ± and ×) which looks better for negative numbers than the simple dash (“-”) which you can create on your keyboard
      --Grotaclas (talk) 06:44, 18 November 2022 (UTC)
