      Template:Iconbox

      From Europa Universalis 4 Wiki
      (Redirected from Template:Achievement)
      Jump to navigation Jump to search
      [view] [edit] Template documentation
      This documentation is transcluded from Template:Iconbox/doc. (edit | history)


      Usage

      One item in a list of icons (achievements, disasters, etc.).

      Parameter Description Status
      1 (first unnamed parameter) Name of achievement required
      2 (second unnamed parameter) In-game/Steam description of achievement required
      link Set to "on" to link to an article with the same name or to the specified link target. If it is not given or empty, there won't be a link optional
      extension Set to the file extension of the achievement image. optional (defaults to .jpg, ignored if image is provided)
      image Name of image file (without File:) optional (defaults to using the first parameter)

      Example

      {{Iconbox|That's a Grand Army|Build up your army to your country's maximum army forcelimit.}}

      That's a Grand Army
      Build up your army to your country's maximum army forcelimit.


      {{Iconbox|World Conqueror|Conquer the World.|link=on}}

      World Conqueror
      Conquer the World.

      {{Iconbox|Mare Nostrum|Restore the Roman Empire and own the entire Mediterranean and Black Sea coast lines.|link=Achievements#Mare Nostrum}}

      Mare Nostrum
      Restore the Roman Empire and own the entire Mediterranean and Black Sea coast lines.
