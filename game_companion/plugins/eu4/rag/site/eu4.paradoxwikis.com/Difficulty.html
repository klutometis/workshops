DifficultyEdit

Different Difficulty settings grant different bonuses to Player or AI nations to adjust the overall game difficulty. If set to Normal, no nations will get bonuses. On Easy, the AI is more forgiving towards Players, whereas on Hard it is far more aggressive.

Lucky nationsEdit

Determines whether there are eight historical, eight random or no lucky nations.

Terra incognita in lobbyEdit

When starting a new campaign with this option active, the random new world will be hidden behind terra incognita in the lobby. When loading an existing save in the lobby, it will also hide provinces which the currently selected country has not discovered yet. This option is always enabled when loading ironman saves.

Use dynamic province namesEdit

Enables or disables the possibility of provinces to change their name when cultural group or owner is changed. If the option is off, provinces can only change name if the player chooses to manually do so.

Show monthly Tax incomeEdit

Show monthly province income as animated map text.

Color 'owned' WastelandsEdit

Wastelands will be colored if a country owns a majority of surrounding provinces.

Exclaves use Region nameEdit

Use region names for Exclaves (e.g. 'Swedish Kongo' instead of 'Sweden').

No limits on Idea GroupsEdit

You can pick any idea group, and are no longer limited from picking the same category all the time.

Limited Country FormingEdit

Enables end-game tags which are countries which are not allowed to form other countries. Disabling this option disables achievements.

Fantasy Random New WorldEdit

Controls the chance of fantasy elements such as highly advanced Native Empires to appear in the Random New World.

Show Start ScreenEdit

Toggles whether Start Screen with information and background about your country and the region is shown when starting a new game.

Multi playerEdit

 
Please help with verifying or updating this section. It was last verified for version 1.29.

Allow players to hotjoinEdit

If on, players can hotjoin the game, making it a multiplayer game. Not possible with Ironman enabled.

Allow players to play the same countryEdit

If on, players can control the same country. Not possible with Ironman enabled.

Only host and observer can saveEdit

If on, only the host or observer will be able to save a multiplayer game.

Only host can pauseEdit

If on, only the host can pause the game.

Editable savegameEdit

If on, players can manually edit saved game files between sessions.

Locked ledgerEdit

If on, players will not be able to open the ledger, preventing usage of it for seeing other countries' armies.

Limited ledgerEdit

If on, the amout of information given by the ledger is reduced.

Use victory cardsEdit

Enables or disables victory cards in the game.

Use age scoringEdit

If on, scores and victory cards will be reset with every new age.

Use teamsEdit

If on, members in a team can only ally each other and not other players.

Free team creationEdit

If on, every player can create a team in the lobby.

Prevent nation ruiningEdit

Blocks certain destructive actions by players that have lost a war as long as the truces after that war are in effect.

Allow province name changeEdit

Allows players to change names of provinces.

Custom setupEdit

 
Please help with verifying or updating this section. It was last verified for version 1.29.
  Available only with the El Dorado DLC enabled.

Custom Nation DifficultyEdit

Determines the amount of points players have available to create custom nations. The more points available, the easier the start.

Points: 50 - 100 - 200 - 400 - 800

Province Tax and ManpowerEdit

Determines the base tax and manpower of all provinces. - normal (historical), random or flat(4-4-3) values

NationsEdit

Determines what countries will populate the map.

Normal Setup
The map will be populated by historical nations and custom nations are enabled.
Historical Setup
The map will be populated by historical nations and custom nations are disabled.
Random Setup
The map will be populated by player-created custom nations and randomly generated nations.
Custom Setup
The map will be populated by only player-created custom nations, all other provinces will be uncolonized. All nations start with a colonist.

Allow adding Nations to Save GameEdit

Allows adding new Custom Nations after loading a Save Game.

Random NationsEdit

Determines where randomly generated nations will get their names and flags from - dynamic or historical.
