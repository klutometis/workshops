      Europa Universalis 4 Wiki:Work needed

      From Europa Universalis 4 Wiki
      Jump to navigation Jump to search

      There's always a number of things that can be improved on the wiki. This is intended as a non-exhaustive list of things that need to be done in order to point editors that don't know what to edit in a useful direction. Everybody is welcome to edit this wiki; if you decide to contribute, please follow the style guidelines.

      Priorities

      High prio

      create/ majorly overhaul

      • CBs and Peace terms
        • Check the availability of peace deals. Maybe add a seperate row for requirements.
      • add info from "00_religious_conversions.tx" to Religion#Centers_of_reformation
      • All country pages
        • See Sweden as an example. All pages should be brought to this level.
      • The HRE page has been split and needs links fixed
        • The country page needs content such as all
      • Yearly Tribal allegiance has probably been replaced by yearly government power
        • Government page needs update regarding the government powers. needs list of all sources and how it translates to the different mechanics
      • The Macrobuilder page needs a major overhaul
      • Figure out what to do about heresys
      • Create a page that explains the two easter egg "Invasion" scenarios (low priority)
      • Figure out more about Centers of Reformation. Info needed :
        • Selection process
        • Range
        • Missionary strength
      • Maybe write a list of known Bugs related to using bookmarks and add it to the Scenarios page
      • Prepare the PU page to become a page related to Dynasties and their spread

      check if uptodate

      • trade nodes map
        • with the new connection between siam and canton
      • Qing/Castille mission image?
      • Mission pages missing images:
        • Songhai branching missions
        • Mali branching missions
        • Brandenburg missions
        • Franconian minor missions
        • Ansbach missions
        • Mossi minor missions
        • Fars missions
        • Aragon missions
      • Add all new modifier types to relevant pages of the wiki (e.g. Culture conversion time)
      • New Rebel types (Janisasries, parliamentarist, Eunuchs, etc.)
      • Some special units might have differing manpower reinforcement costs
      • Several Map Modes to be added to the Legend table.
      • Check if the effects of all rebels are correct(pagan rebels were already done)
      • the distance calculation for colonial range has changed. For example the distance from Ireland to North America has decreased, but some distances in the southern indian and pacific oceans seem to have increased

      minor stuff like structure

      • add information about the disasters Hungarian Revolution and Austrian Revolution to the pages for Austria, Hungary and Austria-Hungary
      • Imperial incidents
      • Events page needs sorting
      • Every page that had Events, Decisions etc. automatically added needs to have these new addendums sorted in
      • Add factor tables to every Diplomatic action that needs it
        • add the conditions which some diplomatic actions gained in common/diplomatic_actions/00_diplomatic_actions.txt to their respective articles
      • The Estate agendas table is missing many detail
        • The base estates had new tables made, the newer ones not yet
      • Ruler page
        • Consider adding Atwix Guide
        • Monarch Life span
        • Papal ruler generation
        • Interregnums
      • Find out more about attitudes and improve the attitudes page
      • Reevaluate the Achievements page at some point
      • Maybe add the Celestial empire reform aswell as info about sincization to the Empire of China Page

      polish/strategy

      • Improve the beginner's guide
      • Guides for all hard, very hard and insane achievements
      • Design a proper layout for the images in Category:Unit_packs.
      • Rewrite (and update) of military leader page
      • polish the Primitives page
      • Polish all the estate pages but especially the domination ones
      • Most Super - Region pages could probably use some polish
      • Polish the page that explains the Livonian Government Building Process
      • rewrite all the events, missions and decisions which have the Category:Computer generated to make them more compact and easier to understand
      • Explain how Units get to the Front/Back row in Battles
      • Create new screenshots for the Production#Example so that they are all for the same situation and then update the example to match the screenshots. Ideally the province has a manufactory, some autonomy, at least one goods produced modifier and at least one production efficiency modifier
      • describe how the great peasants war works and how it can be ended, especially how the GPW_counting_variable can be changed(this has to be tested in game to make sure that information from the game files is accurate and that the AI doesn't switch in and out of the peasant republic reform after their government was changed in a war)
      • better explain how imperial incidents work, especially how the incident events correlate with the options that are visible in the HRE interface if the emperor DLC is active.
      • Merge Envoy#Missionary with Religion#Missionaries. The information should be structured by religion like in Envoy#Missionary, but it needs more icons like in Religion#Missionaries. Afterwards one article can transclude the section from the other one, so that the information can be kept uptodate in one place.
      • add cross-links
      • add information about the unit packs from origins and lions of the north to Downloadable content 2#Cosmetic_packs
      • add Domination unit pack and music packs to Downloadable content‎ 2(including the pre-order DLC "March of Power Music Pack")
      • create a screenshot of the mission preview button and explain the buttons on the Missions or Country_interface#Missions pages and link the explanation on all mission pages which uses the previews
      • add Lions of the North (and all other dlc) to the expansion-template at the top of all section and pages which give features which are (also) unlocked by this DLC
      • Explain this part of the 1.34 patch : "Regiments that reach 0 strength or 0 morale during battle will now retreat immediately."
      • Missions/events that grant flagships- what components do these use?
