      Standard features[edit source]

      When making pages, you often forget some pieces of standard formatting. For one, nearly all pages should have a version template so that they get assigned to the Outdated category once an expansion is released. Secondly, all pages should have at least one category, and if that/those categories have navboxes, one or more navboxes. I'd appreciate it if you added in those things yourself when creating pages so that I don't have to do it. ~ Meneth (talk) 18:11, 27 August 2013 (CEST)

      A reminder to categorize pages you create, thanks. ~ Meneth (talk) 12:16, 2 October 2013 (CEST)
