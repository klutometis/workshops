      Triggered[edit | edit source]

      All events here have the same base chance to happen except where noted otherwise. This is equal chance by individual event, not by category. All events that share the same pulse occur exclusively of one another.

      Disaster events[edit | edit source]

      Main article: Disasters

      The course of the disasters in the game are characterized by triggered events. All disasters have at least a start event and an end event. Mostly they have also events that are triggered by a monthly pulse.

      Yearly pulse[edit | edit source]

      Please help with verifying or updating this section. It was last verified for version 1.35.

      There are 5 pulses, which can trigger events every year. The first yearly pulse triggers the event The Demand for Tribute if its conditions are met. The other four yearly pulses are currently unused.

      5 year pulse[edit | edit source]

      Please help with verifying or updating this section. It was last verified for version 1.35.

      These are four separate 5 year pulses:

      I II III IV
      • The Trail Grows Cold – always if conditions are met
      • Idea group events – Base weight 100
      • Chance for no event - weight 1000
      • Estates events – Base weight 100-400
      • The Royal Baby – Base weight 5
      • Chance for no event - weight 1000
      • Estate led regency events – Base weight 100
      • Propagate religion events – Base weight 100
      • Chance for no event - weight 1000
      • Pretender Rebellion in [dan_rebellious_junior_partner.GetName] – Base weight 100
      • [Root.Monarch.GetName] loses Support in [dan_rebellious_junior_partner.GetName] – Base weight 100
      • Demands of the [Root.GetNobilityOrFallbackName] – Base weight 100
      • Chance for no event – weight 20

      In addition to the events, this pulse contains fallbacks for some things:

      • If the year is 1610 or later and The Papal State does not exist and the global flag counter_reformation is not set:
        • Set global flag counter_reformation
      • If the country has had one of the following flags for at least 1 year and 355 days, the flag is removed:
        • advisor_events_adm
        • advisor_events_adm
        • advisor_events_dip
        • advisor_events_mil
        • shalosh_regalim
