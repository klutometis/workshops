      Tools

      I have worked on these tools to automatically generate content for the wiki

      ck2utils

      my fork is at https://github.com/grotaclas/ck2utils So far it adds the following scripts(I have many more uncommitted stuff which I need to clean up):

      mission_tree_helper.py

      the main use is to process multiple 1920x1080 screenshots, extract the mission trees and merge the multiple images. There should be about 200 pixel overlap so that the script can find the right position. This script can also be used to generate decisions to complete all missions and to switch between mission branches. Completed missions look nicer in screenshots 

      usage: mission_tree_helper.py [-h] [--out OUT] [--generate-mission-tree-completion-decisions] [--cut left upper right lower]
                              [--show-conditions SHOW_CONDITIONS] [--show-mission-conditions [SHOW_MISSION_CONDITIONS ...]]
                              [screenshots ...]

helpers to generate mission images for the wiki

positional arguments:
  screenshots           screenshots to crop

options:
  -h, --help            show this help message and exit
  --out OUT             output image
  --generate-mission-tree-completion-decisions
                        generate decisions which can be used to complete missions to make nice screenshots for the wiki
  --cut left upper right lower
                        get some of the missions from an already processes mission image. The arguments are the position of the top left and bottom right
                        corner of the missions which should be in the new image. The top left mission would be 1 1.
  --show-conditions SHOW_CONDITIONS
                        group mission tree branches in a file by their conditions
  --show-mission-conditions [SHOW_MISSION_CONDITIONS ...]
                        group the mission tree branches by their conditions which contain the listed missions
