      Byzantine missions

      From Europa Universalis 4 Wiki
      Jump to navigation Jump to search

      This article has been verified for the current version (1.37) of the game.

      		Available only with the King of Kings DLC enabled.

      This is a list of all missions of Byzantium. For the missions which Byzantium has when Purple Phoenix, but not King of Kings is active, see Purple Phoenix missions.[1]

      These missions are also available to the Roman Empire if it was Byzantium before and to the Latin Empire if it was formed by Byzantium in the event Papal Assertiveness and to Morea if it was formed by Byzantium in the event Ottomans Advance on Morea. But they are not available to these countries if they were created in other ways.
